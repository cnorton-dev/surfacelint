# Security Policy

## Supported versions

SurfaceLint is pre-1.0 software. Security fixes are applied to the latest development release.

## Reporting a vulnerability

Please do not publish a suspected vulnerability before maintainers have had a reasonable opportunity to investigate it.

Until a dedicated security contact is configured, open a GitHub Security Advisory for the repository rather than a public issue.

Include:

- affected version or commit
- operating system
- reproduction steps
- expected vs. observed behavior
- potential impact

SurfaceLint is a defensive assessment tool. Reports about ways to turn it into an intrusive scanner or to bypass authorization boundaries are especially important.
